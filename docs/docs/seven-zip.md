Launcher gọi `7z2409-x64.exe /S`. Chương trình nằm ở `C:\Program Files\7-Zip\`.

## Kiểm tra

Mở thư mục đó và chạy `7z.exe`, hoặc chuột phải một file trong Explorer. Menu ngữ cảnh có mục 7-Zip nếu cài thành công.

## Nén một thư mục

```
"C:\Program Files\7-Zip\7z.exe" a D:\luu-tru.7z D:\ho-so
```

Một số phần mềm khác trong catalog khai báo 7-Zip là phụ thuộc. Launcher sẽ cài 7-Zip trước những gói đó.
