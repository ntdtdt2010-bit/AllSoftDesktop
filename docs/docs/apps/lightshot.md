# Lightshot

**Lightshot** là tiện ích chụp màn hình gọn nhẹ, giúp bạn chụp lại thông báo lỗi phần mềm hoặc nội dung cần lưu trữ chỉ trong vài giây.

## Cách sử dụng
1. **Kích hoạt chụp màn hình**:
   - Nhấn phím `PrtSc` (Print Screen) trên bàn phím máy tính. Màn hình sẽ tối nhẹ lại.
2. **Chọn vùng cần chụp**:
   - Kéo giữ chuột trái để quét vùng hình ảnh bạn muốn chụp.
3. **Thêm chú thích**:
   - Dùng thanh công cụ dọc bên phải vùng chọn: Bút vẽ, Mũi tên chỉ dẫn, Viết chữ `T`, Đóng khung chữ nhật.
4. **Lưu hoặc sao chép**:
   - Nhấn tổ hợp phím `Ctrl + C` để sao chép ảnh vào bộ nhớ tạm (dán ngay vào Zalo/Email).
   - Nhấn tổ hợp phím `Ctrl + S` hoặc bấm biểu tượng đĩa mềm để lưu ảnh thành tệp `.png`.
