# VNPT-CA Token Manager

**VNPT-CA Token Manager** là phần mềm quản lý thiết bị ký số USB Token do VNPT phát hành, phục vụ việc ký số văn bản, hóa đơn điện tử và kê khai thuế, hải quan.

## Quy trình sử dụng
1. **Cắm thiết bị USB Token** vào cổng USB máy tính. Đèn LED trên USB sẽ sáng ổn định.
2. Khởi chạy ứng dụng **VNPT-CA Token Manager** từ màn hình Desktop hoặc khay hệ thống (System Tray).
3. **Đăng nhập thiết bị**:
   - Nhập mã PIN của USB Token (mặc định ban đầu do nhà cung cấp bàn giao).
   - *Lưu ý*: Nhập sai mã PIN quá 5 lần thiết bị sẽ tự động khóa để bảo mật. Hãy liên hệ bộ phận Kế toán / IT nếu bị khóa.
4. **Kiểm tra thời hạn chứng thư**:
   - Bấm vào mục `Chứng thư số` để kiểm tra ngày hết hạn chứng thư nhằm gia hạn kịp thời trước mùa quyết toán.
