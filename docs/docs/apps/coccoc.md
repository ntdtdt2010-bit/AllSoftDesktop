# Trình duyệt Cốc Cốc

**Cốc Cốc** là trình duyệt web phát triển trên nền tảng Chromium, được tối ưu riêng cho thói quen duyệt web của người dùng Việt Nam.

## Tính năng nổi bật
- **Tải tệp đa luồng**: Tự động bắt link tải video, âm thanh và tài liệu với tốc độ cao.
- **Tích hợp từ điển**: Nhấp đúp vào bất kỳ từ tiếng Anh nào để tra nghĩa tức thì.
- **Tự động thêm dấu**: Hỗ trợ gõ tiếng Việt nhanh chóng ngay trên thanh tìm kiếm mà không sợ lỗi bộ gõ.
- **Chặn quảng cáo phiền toái**: Tích hợp sẵn bộ lọc quảng cáo pop-up độc hại.

## Thao tác cơ bản
1. **Đặt làm trình duyệt mặc định**:
   - Vào `Cài đặt` (Settings) > `Trình duyệt mặc định` > Bấm `Chọn làm mặc định`.
2. **Xóa dữ liệu duyệt web**:
   - Nhấn tổ hợp phím `Ctrl + Shift + Del` > Chọn khoảng thời gian > Bấm `Xóa dữ liệu`.
3. **Phóng to / Thu nhỏ trang**:
   - Giữ phím `Ctrl` và lăn chuột giữa, hoặc nhấn `Ctrl + (+)` / `Ctrl + (-)`.
