# VNeGP Client Agent

**VNeGP Client Agent** là ứng dụng cầu nối giữa trình duyệt web và thiết bị chữ ký số khi thực hiện các nghiệp vụ đấu thầu trên Hệ thống mạng đấu thầu quốc gia (muasamcong.mpi.gov.vn).

## Các bước chuẩn bị trước khi ký số
1. Cắm USB Token vào máy tính.
2. Khởi chạy **VNeGP Client Agent** (đảm bảo biểu tượng agent hiển thị màu xanh lá ở khay đồng hồ góc phải dưới màn hình).
3. Sử dụng trình duyệt được hỗ trợ (khuyên dùng Chrome hoặc Edge) đăng nhập vào cổng Đấu thầu quốc gia.
4. Khi hệ thống yêu cầu xác nhận ký điện tử:
   - Một cửa sổ bảo mật của VNeGP Agent sẽ bật lên.
   - Chọn đúng chứng thư số của đơn vị và nhập mã PIN USB Token.
   - Bấm `Ký số` để hoàn tất giao dịch nộp thầu.

## Xử lý khi trang web báo "Không tìm thấy Agent"
- Nhấp chuột phải vào biểu tượng VNeGP Agent ở khay hệ thống > Chọn `Khởi động lại Agent`.
- Tải lại trang web (`F5`) và thực hiện ký lại.
