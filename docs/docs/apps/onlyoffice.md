# ONLYOFFICE Desktop Editors

**ONLYOFFICE** là bộ ứng dụng văn phòng mã nguồn mở mạnh mẽ, có độ tương thích cao với định dạng Microsoft Office (`.docx`, `.xlsx`, `.pptx`).

## Các ứng dụng tích hợp
- **Document (Văn bản)**: Soạn thảo công văn, hợp đồng, báo cáo định dạng docx.
- **Spreadsheet (Bảng tính)**: Xử lý số liệu, bảng biểu, hơn 400 hàm tính toán tương đương Excel.
- **Presentation (Trình chiếu)**: Thiết kế slide thuyết trình chuyên nghiệp.
- **PDF Form**: Điền form và tạo biểu mẫu tài liệu điện tử.

## Thao tác cơ bản
1. **Mở tệp từ máy**: Bấm biểu tượng thư mục ở menu bên trái hoặc kéo thả tệp vào cửa sổ.
2. **Lưu định dạng chuẩn**: Mặc định tệp lưu dạng `.docx` / `.xlsx` giúp mở dễ dàng trên mọi máy tính.
3. **Xuất PDF**: Vào `Tệp` (File) > `Lưu dưới dạng` (Save as) > Chọn `PDF Document`.
